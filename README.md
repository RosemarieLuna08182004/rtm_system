## TO START

- install requirements
- restore database backup (if applicable)

- Backend/Server

1. npm install
2. setup .env
3. npm run start <!-- server/backend side >

- Frontend/Client

1. npm install
2. setup eas, expo, etc.
3. npm run start <!-- client/frontend side >
4. run on emulator or Expo Go
